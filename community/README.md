# Community Plugins

Discover amazing plugins created by the Lunacy community!

## Submit Your Plugin

Built something cool? Share it with the community!

1. Host your plugin on GitHub
2. Add `lunacy-plugin` topic to your repository
3. Submit a PR adding your plugin to this list

See [CONTRIBUTING.md](../CONTRIBUTING.md) for submission guidelines.

## Categories

Once we have community plugins, they'll be organized into:

- **Design Tools** - Layer manipulation, styling, effects
- **Export & Conversion** - Custom formats, batch processing
- **AI & Automation** - Smart tools, content generation
- **Integration** - External services, APIs, databases
- **Utilities** - Helpers, validators, cleanup tools
- **Analytics** - Metrics, reporting, tracking

## Guidelines

Community plugins should:

- Have clear documentation
- Include working `plugin.jsonc`
- Specify dependencies
- Follow best practices
- Be actively maintained

## Finding Plugins

Browse GitHub for plugins with the [`lunacy-plugin`](https://github.com/topics/lunacy-plugin) topic.
