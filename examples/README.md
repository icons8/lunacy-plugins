# Plugin Examples

Learn by example! This directory contains working plugin examples to get you started.

## Getting Started Examples

### [Hello World (Node.js)](./hello-world-node/)

Basic plugin showing toast notifications.

- Simple HTTP API call
- Minimal configuration
- Quick start template

### [Hello World (Python)](./hello-world-python/)

Python version of Hello World.

- Python requests library
- Basic error handling
- Cross-platform compatible

### [Hello World (C#)](./hello-world-csharp/)

C# version demonstrating development workflows.

- Development mode: `dotnet run`
- Production mode: compiled binary
- NativeAOT support

## Installation

Each example can be installed by copying its directory to your Lunacy plugins folder:

### Linux

```bash
cp -r example-name ~/.local/share/Icons8/Lunacy/Plugins/
```

### Windows

```cmd
xcopy /E /I example-name "%LOCALAPPDATA%\Icons8\Lunacy\Plugins\example-name"
```

### macOS

```bash
cp -r example-name ~/Library/Application\ Support/Icons8/Lunacy/Plugins/
```

## Running Examples

Run through Lunacy's plugin menu: **Plugins → [Plugin Name] → [Command]**
